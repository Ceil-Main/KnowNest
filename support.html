常見問題

怎麼把截圖變成知識節點？

點畫面下方的「快速建點」，選擇截圖後按「本機辨識填入欄位」，知巢會在手機上辨識文字，整理出標題與參數、公式、禁忌、代碼等細節，確認或修改後即可建立節點。

怎麼一次用多張圖片建立星系？

在「照片」選取多張截圖，按分享並選擇「知巢」，看到「已加入知巢」後打開知巢，就會出現辨識與確認畫面，按「建立星系」即可。也可以從左上角的標誌打開選單，選「多圖建立星系」。

分享選單裡找不到「知巢」？

在分享選單的 App 列最右邊點「更多」，找到「知巢」並開啟，也可以把它拖到前面方便下次使用。

怎麼在畫布加入圖片、檔案或連結？

長按畫布空白處，選擇圖片、檔案或連結，並可直接連到指定節點。也可以在節點的「思維鏈路關聯」區塊加入。

怎麼分享給朋友，或拿給 AI 對話？

在左側選單的資料夾或畫布按「⋯」，選「分享」會產生 .knownest 檔，對方用知巢打開即可匯入；選「分享給 AI」會產生 Markdown，可複製貼到 ChatGPT、Claude、Gemini 等 AI 工具。節點本身也能從詳細面板右上角分享。

我的資料存在哪裡？會不會不見？

所有資料只存在你的手機上，知巢沒有雲端伺服器。刪除 App 會一併刪除資料，換手機前請先在「匯入 / 備份」匯出 JSON 備份。節點裡的圖片與檔案只存在本機，不會包含在備份或分享檔中。

Gemini 是什麼？一定要設定嗎？

不需要。知巢預設使用手機上的本機辨識。Gemini 是選用功能：在「視覺引擎設定」輸入你自己的 Gemini API Key 後，可以讓 Google Gemini 分析截圖；第一次傳送前會先詢問你是否同意，也可以隨時撤回。

匯入 JSON 失敗怎麼辦？

知巢會自動清理 Markdown 標記、引用標記與常見的格式錯誤。若仍然失敗，請把錯誤訊息與 JSON 內容寄給我們。

辨識結果不準確？

請盡量使用清晰、文字較大的截圖，辨識後可以直接修改標題與細節。若特定版面總是辨識錯誤，歡迎附上截圖來信，協助我們改善。
