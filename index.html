知巢 KnowNest 隱私權政策

生效日期：2026 年 11 月 3 日

概要

知巢是一個在你自己裝置上運作的個人知識圖譜 App。知巢沒有帳號系統、沒有自己的伺服器，也沒有任何廣告、追蹤或數據分析工具。我們（知巢的開發者）不會收集、存取或販售你的任何資料。

存在你裝置上的資料

你建立的畫布、資料夾、節點、細節與連線，你加入的圖片與檔案，你輸入的 Gemini API Key，以及深淺色等設定，全部只儲存在你的裝置上。刪除知巢 App 時，這些資料會一併刪除。若你開啟了 iCloud 或裝置備份，系統備份可能包含這些資料，並依 Apple 或 Google 的備份政策處理。

照片與檔案

知巢只會讀取你透過系統選擇器主動選取的圖片與檔案，不會瀏覽你的整個相簿。從相簿「分享」到知巢的圖片，會暫存在知巢與其分享擴充功能共用的 App 資料夾中，知巢讀取後即刪除暫存檔。

本機文字辨識

截圖的文字辨識預設在你的裝置上執行（iPhone 使用 Apple Vision，Android 使用 Google ML Kit 的離線模型），圖片不會被上傳。

選用功能：Google Gemini（第三方 AI）

只有在你自行輸入 Gemini API Key，並在第一次使用前明確同意後，知巢才會在你按下「Gemini 解析」或「Gemini 提煉星系總綱」時，把你選擇解析的截圖，或要提煉的星系筆記文字，從你的裝置直接傳送到 Google 的 Gemini API。這些資料不會經過知巢開發者，由 Google 依其《Gemini API 附加服務條款》與《Google 隱私權政策》處理，並提供不低於本政策的保護。你可以隨時在「視覺引擎設定」撤回同意或清除 API Key，之後知巢只會使用本機辨識。

分享與匯出

只有在你主動操作時，知巢才會產生分享檔（.knownest）、JSON 備份或給 AI 用的 Markdown，並透過你選擇的 App（例如 AirDrop、LINE、Email）傳送。這些內容不包含你加入的圖片與檔案（連結節點的網址除外）。傳送後的資料由你選擇的 App 與接收者依其政策處理。

開啟連結

你在連結節點或設定頁點選的網址，會以裝置的瀏覽器開啟，並由該網站依其政策處理。

兒童隱私

知巢不會收集任何人的個人資料，包括 13 歲以下的兒童。

資料保留、撤回同意與刪除

由於所有資料只存在你的裝置上，你可以隨時在 App 內刪除節點、畫布或資料夾，或直接刪除 App 來清除全部資料。開發者無法存取你的資料，因此無法、也不需要替你保存或刪除。傳送給 Google Gemini 的資料，請依 Google 提供的方式管理。

政策變更

如果本政策有所變更，我們會更新此頁面與生效日期；涉及資料使用方式的重大變更，會在 App 內提示你。

聯絡我們

對本政策有任何問題，請透過 App Store 上「知巢」頁面的開發者支援連結與我們聯絡。
